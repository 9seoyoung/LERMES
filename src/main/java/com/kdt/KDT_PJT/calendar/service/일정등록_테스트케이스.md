## 관리자인 경우 (권한 번호 3번 이하)
### 공식 일정(PRVT_YN=0) 등록 가능 <br>
요청
```json
{
  "cohortSn": 100,
  "eventBgngDt": "2025-09-18T09:00:00",
  "eventEndDt":  "2025-09-20T12:00:00",
  "eventNm":     "관리자 공식일정 등록",
  "rmrkCn":      "공식일정임 이때는 cohortSn필수",
  "prvtYn":      0
}
```
응답
```json
{
    "calSn": 9,
    "cohortSn": 100,
    "eventBgngDt": "2025-09-18T09:00:00",
    "eventEndDt": "2025-09-20T12:00:00",
    "eventNm": "관리자 공식일정 등록",
    "rmrkCn": "공식일정임 이때는 cohortSn필수",
    "userSn": 20,
    "eventRegDt": "2025-09-18T16:30:14",
    "prvtYn": 0
}
```
### 개인 일정(PRVT_YN=1) 등록 가능
요청
``` json
{
  "eventBgngDt": "2025-09-18T09:00:00",
  "eventEndDt":  "2025-09-20T12:00:00",
  "eventNm":     "관리자 개인일정",
  "rmrkCn":      "ㅇㅇ",
  "prvtYn":      1
} 
```
응답
``` json
{
    "calSn": 12,
    "cohortSn": null,
    "eventBgngDt": "2025-09-18T09:00:00",
    "eventEndDt": "2025-09-20T12:00:00",
    "eventNm": "관리자 개인일정",
    "rmrkCn": "ㅇㅇ",
    "userSn": 20,
    "eventRegDt": "2025-09-18T16:44:14",
    "prvtYn": 1
}
```
