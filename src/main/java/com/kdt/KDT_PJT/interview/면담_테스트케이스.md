## 면담 확정 (대표, 직원, 강사만 가능)
`PUT` /api/interview/confirm/{itvSn}

```json
{
  "itvDay": "2025-09-22",
  "itvTime": "09:00",
  "itvPlc": "면담장소",
  "itvPicAns": "면담 신청자에게 할말(요청사항)"
}
```

본인 계급에 해당하면 update 완료, 이미 확정된애는 에러.
